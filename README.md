# TripleCalendar
jalali,miladi,hijri calendar

this is a jalali calendar with miladi and hijri calendars.
to use this tool you have to pass this easy steps:
1- install php 8.4
2- install IIS (or apache,nginx,php built-in server, ......)
3- mysql Server(on local or host)
    you have to set datbase parameters in db.config. customize db.sql based on your databse name and ....
    create a table with same name in db.php and run db.sql query.
this is made by bootstrap css and js

you can customize events and holidays.add,remove events and some other tools
